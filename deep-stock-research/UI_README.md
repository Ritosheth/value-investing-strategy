# 本机深度研究启动界面

双击工作区根目录的 `启动深度研究界面.command`，浏览器会打开：

`http://127.0.0.1:8765`（如果该端口被占用，会自动顺延到下一个可用端口）

界面支持输入多个 A 股、港股或美股代码，并保存研究要求、研究周期、风险偏好和重点方向。点击运行后，后台先调用 Futu/OpenD 和本地选股模型采集证据，再调用本项目的 `scripts/collect_deep_research_data.py`，结果位于：

`outputs/deep_research/YYYYMMDD/[股票代码]/`

每个股票目录包含：

- `research_request.md`：本次界面输入的研究要求；
- `research_raw.json`：原始证据及缺口；
- `research_derived.json`：确定性评分、研究姿态、影子仓位区间、相对估值和 FCFF DCF；
- `research_brief.md`：中文证据简报，包含保守/基准/乐观合理价值与 DCF 目标价区间。

系统同时输出两类估值。相对估值按照 Futu 返回的类型计算：PE 使用“TTM 每股收益 × 历史 PE 分位数”，PB 使用“每股净资产 × 历史 PB 分位数”，PS 使用“每股营业收入 × 历史 PS 分位数”，不会把 PB/PS 误当成 PE。非金融公司还会生成 5 年两阶段 FCFF DCF，包含三情景目标价、WACC/永续增长率敏感性和当前价格隐含增长率；输入来自多年年报，增长率按绝对营业收入计算以消除股本变化影响。金融股自动停用普通 FCFF DCF，保留 PB 相对估值并提示改用股利折现或剩余收益模型。

DCF 中的无风险利率、股权风险溢价、Beta、永续增长率和现金流利润率都是显式假设，保存在 `research_derived.json` 中供审计。目标价是情景估值，不是券商一致预期或确定性收益承诺。

日期目录下还会有 `evidence_bundle.json`，保存本次 Futu/OpenD 与本地模型采集的证据总包。

这层界面不会自动下单，也不会把缺失数据当成中性证据。完整的联网深度研报需要在证据底稿基础上继续核验官方披露、财报和当前外部资料。
